## 🔧 Para Usar no VS Code:

1. **Abra a pasta no VS Code**:
   ```
   File → Open Folder → Selecione a pasta do seu projeto
   ```

2. **Para visualizar com Live Server**:
   - Instale a extensão "Live Server"
   - Clique com botão direito em `index.html`
   - Selecione "Open with Live Server"

3. **Para adicionar favicons reais**:
   - Acesse https://favicon.io/ ou https://realfavicongenerator.net/
   - Faça upload do seu logo/design
   - Baixe os arquivos gerados
   - Substitua os placeholders na pasta `favicons/`
